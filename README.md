# MrCorrect
# پروژه جامع ERP با C# WPF

این پروژه یک سیستم برنامه‌ریزی منابع سازمانی (ERP) جامع و یکپارچه برای پلتفرم دسکتاپ ویندوز است. این نرم‌افزار به عنوان یک نسخه مدرن و بازنویسی شده از یک پروژه قدیمی مبتنی بر MS Access 2003 ADP توسعه داده شده است.

---

## 🚀 ماژول‌ها و قابلیت‌های اصلی

این سیستم ERP شامل مجموعه‌ای کامل از ماژول‌های مورد نیاز یک کسب‌وکار است:

-   **حسابداری**: مدیریت اسناد، حساب‌ها، و عملیات مالی.
-   **خرید و فروش**: مدیریت فاکتورها، مشتریان و تأمین‌کنندگان.
-   **انبارداری**: کنترل موجودی، ورود و خروج کالا.
-   **حسابداری صنعتی**: محاسبه بهای تمام شده محصولات.
-   **اتوماسیون اداری**: مدیریت فرآیندهای داخلی و مکاتبات.
-   **مدیریت چک**: ثبت و پیگیری چک‌های دریافتی و پرداختی.
-   **حقوق و دستمزد**: محاسبه حقوق کارکنان بر اساس قوانین.
-   **مدیریت ویزیتورها**: برنامه‌ریزی و ردیابی عملکرد بازاریابان.

---

## 🛠️ پشته فناوری (Technology Stack)

این پروژه با استفاده از فناوری‌های مدرن مایکروسافت توسعه داده شده است:

-   **زبان برنامه‌نویسی**: **C#**
-   **فریم‌ورک**: **.NET 8**
-   **رابط کاربری (UI)**: **WPF (Windows Presentation Foundation)**
-   **نوع برنامه**: Windows Desktop Application
-   **پایگاه داده**: **SQL Server** (حداقل نسخه 2008 R2)
-   **دسترسی به داده‌ها (Data Access)**:
    -   `System.Data.SqlClient` برای ارتباط پایه با دیتابیس.
    -   **Dapper** به عنوان یک Micro-ORM برای اجرای کوئری‌های بهینه.
-   **گزارش‌گیری**: ** 2023.1.1 Stimulsoft Reports**

---

## 📜 پیشینه پروژه

این نرم‌افزار در اصل یک مهاجرت (Migration) کامل از یک پروژه قدیمی **Microsoft Access 2003 ADP** است. منطق برنامه که در ابتدا با **VBA** و `ADODB.Recordset` نوشته شده بود، به طور کامل به زبان **C#** و معماری **Code-Behind** در محیط WPF بازنویسی شده است. هدف اصلی از این تبدیل، مدرن‌سازی، افزایش کارایی و قابلیت نگهداری پروژه بوده است.

---


## 📦 انتشار و استقرار (Deployment)

برای سهولت در نصب و توزیع، پروژه به صورت یک **فایل اجرایی واحد (Publish Single EXE)** خروجی گرفته می‌شود. این روش نیاز به نصب پیش‌نیازهای پیچیده را از بین برده و اجرای برنامه را برای کاربر نهایی ساده می‌کند.

---

## 📋 پیش‌نیازها

برای اجرا و توسعه پروژه به موارد زیر نیاز است:

-   **.NET 8 Desktop Runtime**
-   دسترسی به یک نمونه (Instance) از **SQL Server نسخه 2008 R2 یا بالاتر**.
-   (برای توسعه) Visual Studio 2022
