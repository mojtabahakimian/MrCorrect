3. **با موس و کیبورد در برنامه کار کن.** ساختن فایل `.cs` تستی یا صدا زدن

4. تست‌نشده را ادعا نکن. نمی‌دانی؟ بنویس «نمی‌دانم».

**بعد از هر کار ۳ ثانیه صبر کن** (نوشتن دسته‌ای، هر ۷۵۰ms).

```sql
SELECT LOG_ID,USER_NAME,ACTION,CATEGORY,SEVERITY,ENTITY,ENTITY_KEY,FORM_NAME,TITLE,DETAIL
FROM dbo.VW_SYS_AUDIT_TIMELINE WHERE LOG_ID > @شروع ORDER BY LOG_ID;
```

## ۳.۱ پیش‌نمایش ≠ چاپ
با دست: (الف) پیش‌نمایش بگیر و **بدون چاپ** ببند. (ب) دوباره باز کن و
واقعاً چاپ کن (Microsoft Print to PDF هم قبول است). (ج) از داخل گزارش
خروجی فایل بگیر.

```sql
SELECT LOG_ID,ACTION,SEVERITY,ENTITY_KEY,FORM_NAME,TITLE
FROM dbo.VW_SYS_AUDIT_TIMELINE
WHERE LOG_ID>@شروع AND ACTION IN('PREVIEW','PRINT','EXPORT') ORDER BY LOG_ID;
```

| کار | `ACTION` | `SEVERITY` |
|---|---|---|
| پیش‌نمایش | `PREVIEW` | ۱ |
| چاپ | `PRINT` | ۲ |
| خروجی فایل | `EXPORT` | ۳ |

⭐ **مهم‌ترین بررسی:** آیا `TITLE` نام واقعی گزارش را دارد یا فقط `WINRPT`؟
❌ اگر پیش‌نمایش و چاپ یک `ACTION` ساختند، یا چاپ هیچ رویدادی نساخت → باگ.

## ۳.۲ خروجی اکسل از سه فرم
روی **سه فرم متفاوت** (لیست کالا، لیست مشتری، یک گزارش) دکمه‌ی خروجی
اکسل را بزن. تعداد ردیف هر جدول را از خود فرم یادداشت کن.

| فرم | ثبت شد؟ | `FORM_NAME` | تعداد ردیف درست؟ |
|---|---|---|---|

انتظار: `SEVERITY=3` · `TITLE` تعداد ردیف را داشته باشد · `FORM_NAME`
نام همان فرم باشد.

> خروجی اکسل از یک نقطه‌ی مرکزی می‌گذرد (۱۱۹ فرم). اگر هیچ‌کدام ثبت نشد،
> **حتماً بنویس دقیقاً روی چه دکمه‌ای کلیک کردی** — ممکن است آن فرم مسیر
> دیگری داشته باشد و این یافته‌ی مهمی است.
