## ۶.۶ همزمانی (اگر دو کامپیوتر داری)
دو کاربر هم‌زمان کار کنند.
```sql
SELECT USER_NAME,MACHINE_NAME,CLIENT_IP,COUNT(*) FROM dbo.VW_SYS_AUDIT_TIMELINE
WHERE LOG_ID>@شروع GROUP BY USER_NAME,MACHINE_NAME,CLIENT_IP;

SELECT SESSION_ID,COUNT(*) کل,COUNT(DISTINCT SEQ) یکتا FROM dbo.SYS_AUDIT_EVENT
WHERE LOG_ID>@شروع AND SESSION_ID IS NOT NULL GROUP BY SESSION_ID;
```
انتظار: هر کاربر با IP خودش · `کل` = `یکتا`.
